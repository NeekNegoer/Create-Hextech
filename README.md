# Create: Hextech

A Create addon for Minecraft 1.21.1 (NeoForge) that brings Arcane's hextech and shimmer to the game.

- Mod ID: `hextech`
- Targets: NeoForge 21.1.256, Create 6.0.10
- Optional/compat: Sable, Create: Aeronautics, Create: Connected

## Getting started (GitHub Codespaces)

1. Open a Codespace on this repo. `scripts/setup.sh` runs automatically and creates the Gradle wrapper.
2. Build: `./gradlew build`
3. Test on a dev server: `./gradlew runServer` (Codespaces has no display, so `runClient` needs a local machine).
